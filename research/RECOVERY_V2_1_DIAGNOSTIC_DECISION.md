3. Use the same human rubric for both arms: literal operation/relation/entity preservation; interval notation; Arabic grammar; source-owned mathematical/numerical fidelity; reasoning boundaries; and faithfulness to flawed English. Report English source/label concerns separately. Record actual reviewer identity, explicit attestation and actual UTC time. Independently review corrections. Where feasible use two bilingual reviewers and adjudicate disagreement, retaining each original record.
4. Report paired wins/ties/losses/unresolved, hard-validation failures, transport/interruption outcomes, high-risk substitutions, correction proposals and measured review time. Show strata and source-group clustering. The [separate offline assessment workflow](DIAGNOSTIC24_ASSESSMENT_V2_1.md) implements these report contracts; it separates error ties from faithful ties and retains all twelve pairs. No actual diagnostic assessments or semantic results exist yet. No heuristic flag is a human label. Unresolved review is not a correct translation.
5. A conservative **development gate**, not an efficacy threshold: no hard Arabic/math/numerical/boundary violations; human-confirmed literal translations for both known serious sentinels; resolution of interval/possessive and clear digit-agreement errors; no new high-severity control regressions. A critical error or unresolved sentinel blocks wider recovery and triggers offline analysis. Passing only justifies designing a larger independently reviewed experiment.

Twelve purposive pairs have low statistical power, correlated items and reuse development failures. The intervention bundles context, glossary and prompt changes, so it cannot attribute a benefit to one component. Temperature zero and fixed seed do not guarantee cross-device bitwise generation reproducibility. Counterbalanced order mitigates but cannot remove order/runtime effects. There is no held-out accuracy claim, corpus-quality guarantee or downstream training evidence.
