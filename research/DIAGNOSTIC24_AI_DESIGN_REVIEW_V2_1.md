## Fairness and preserved settings

For every slot, the control request exactly matches the existing v1 `request_for(target)` with no retry-history modifier. Both arms have identical non-message settings: model/digest, temperature0, seed42, context4096, generation512, structured Arabic-only schema, thinking off, streaming off and keep-alive10m. Both use the same hard language, mathematics, number and boundary validator. Control/context-first alternates six/six, and each slot/arm gets one opportunity.

The messages differ materially: control contains a synthetic few-shot example; contextual removes that dialogue and adds full field/problem/adjacent-step context, glossary, revised instructions and an explicit digit-agreement example. Thus it is a defensible comparison of complete translation policies under common settings, not a controlled ablation of context or glossary alone. Inputs are not token-matched, and runtime/order effects are not eliminated by alternation. Fixed seed and temperature do not guarantee bitwise generation reproducibility across software/device versions.

The existing size gate uses serialized UTF-8 bytes plus a512 generation allowance and128 margin against4096. This is a conservative proxy, not a measurement of the installed tokenizer/chat-template token count. The longest contextual request is3425 serialized bytes, leaving31 units under that proxy. Local model/runtime verification and eventual returned runtime metadata remain necessary; CI does not prove absence of server-side truncation.

All24 opportunities are fixed reservations: one per arm, two per slot overall, at most512 generated tokens each. Transport failures, crashes and interrupted reservations remain spent; no retry, replacement, refund, alternate allowance or renewed old20 is permitted. Partial runs remain partial. ## Source reasoning is not translation fidelity

The review package includes every original step, native rating, label and mask. Its separate AI source notes include these independently checked issues:

- Circle geometry: the upper centre-distance condition alone is insufficient; radii7 and1 at distance5 form a counterexample. Squaring the preceding negative-side inequality is not equivalent. The full distance conditions would imply `-36 <= k <= 104`, but that is a review note, never a source replacement.
- Base representation: `4^2 <= 62 < 4^3` meets the source's own three-place condition, despite its last comment that64 is too big.
- Disjoint-pair context: choosing `{1,4}` after `{1,2}` violates the stated no-shared-element constraint.
- Barrel arithmetic in unselected context: `1500/(2000/3) = 9/4`, not `27/4`. The radius target is assessed separately.
- Fair-coin comparison: exchangeability of two equal-length independent fair-coin counts plus the extra toss gives probability1/2. The source's0.5078 needs separate reasoning/approximation review.
- Decimal wording is context-dependent: purely periodic from the first digit differs from eventually repeating; denominator coprimality needs the intended interpretation/reduction assumptions. Period dividing12 does not require least period exactly12. Do not turn this nuance into a universal error label.

Some source mistakes may already be correctly marked negative. Native positive labels do not establish mathematical truth either. Preserve all original labels and masks. Translate a wrong multiple-choice option faithfully, without changing Circle into Sphere because Sphere solves the problem.
